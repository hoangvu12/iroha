# Domain docs

This is a single-context repository.

Before exploring or changing the code:

- Read the root `CONTEXT.md`.
- Read relevant ADRs under `docs/adr/`.
- Proceed silently if a referenced document is absent.
- Use canonical terms from `CONTEXT.md`.
- Surface any proposed change that contradicts an ADR rather than silently overriding it.

The `/domain-modeling` workflow updates the glossary and creates ADRs when decisions genuinely warrant them.
