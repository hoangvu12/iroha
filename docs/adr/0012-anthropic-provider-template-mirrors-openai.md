# Anthropic Provider Template mirrors the OpenAI template's capability defaults

The new `anthropic` Provider Template at `src/providers/templates.ts` sets all five existing capabilities — `chat`, `streaming`, `tools`, `structuredOutput`, `responses` — to `true`, matching the OpenAI template's defaults. The `AnthropicInferenceAdapter` translates OpenAI `/v1/responses` requests to Anthropic `/v1/messages` using Anthropic's `output_config.format` (the GA structured-outputs mechanism modeled on Bifrost's `responses.go:4010-4016`); the legacy beta `output_format` is the fallback for older models and the tool-based emulation is reserved for sibling Targets (Vertex / Bedrock Mantle / Azure) that reject the GA shape. The build-known-models list mirrors the current `Model` enum from the Anthropic TypeScript SDK, covering Claude Opus 5, Sonnet 5, Fable 5, Mythos 5, Opus 4.8 / 4.7 / 4.6 / 4.5, Sonnet 4.6 / 4.5, Haiku 4.5, and Mythos Preview — both alias and dated forms. The key test uses the generic OpenAI-compatible probe because Anthropic's `/v1/models` is OpenAI-shaped. We rejected conservative defaults (`responses: false` because Anthropic lacks a Responses endpoint — but the adapter translates at the boundary, so the route is reachable and a `false` would silently disable a working capability), extending the capability matrix with Anthropic-specific fields such as `thinking`, `cache_control`, `documents`, `image_input`, `pdf_input`, `structured_outputs`, and `effort` (deferred — unknown JSON fields are already preserved at the passthrough boundary per `docs/capability-matrix.md:20`, and adding slots before there is evidence that Owners need first-class visibility into which Anthropic features are supported adds matrix weight without payoff), and advertising Anthropic as a Provider that does not have `/v1/responses` (false — the adapter exposes the route). LiteLLM's Anthropic provider supports `/v1/responses` (`litellm/proxy/response_api_endpoints/endpoints.py:118-126`, `docs.litellm.ai/docs/response_api`) and Bifrost's Anthropic provider supports it as a first-class shape (`core/providers/anthropic/responses.go`, `docs.getbifrost.ai/providers/supported-providers/anthropic`); two of three production gateways make the same capability claim this ADR records.
